# Sirui Chen - Portfolio

Personal portfolio site hosted at https://irischensr.github.io

## About

Data and business analytics professional with experience in SQL, Python, and machine learning. Currently an MMA student at McGill University, previously B.S. in Information Management at Shanghai University.

## Files

- index.html - portfolio website (single-page, Tailwind + Font Awesome)
- main.py - local helper script that loads secrets from .env via python-dotenv
- requirements.txt - Python dependencies
- .env - local secrets (not tracked by git)

## Local development

Create a virtual environment, install dependencies with `pip install -r requirements.txt`, then run `python3 main.py`.

## Deployment

Pushed to the `main` branch and published automatically via GitHub Pages.
